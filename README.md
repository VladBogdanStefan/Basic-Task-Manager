# Employee and Task Management System

A desktop application developed in **Java** for the efficient management of employees and organizational tasks. This project was built to apply Object-Oriented Programming (OOP) principles, custom data structures, and Graphical User Interface (GUI) design using **Java Swing**.

## 🚀 Key Features

* **Task Management:** Create, edit, and delete tasks. The system supports both simple standalone tasks and complex tasks (composed of multiple sub-tasks).
* **Employee Assignment:** Allocate specific tasks to individual employees and track their completion status.
* **Filtering and Sorting:** Advanced sorting capabilities to organize employees and tasks based on various criteria (e.g., priority, deadline, or assignee).
* **Data Persistence:** Automatic saving and loading of application state upon startup and shutdown using Java **Serialization**.
* **Custom GUI:** Intuitive, custom-built UI components developed with Java Swing and AWT for a seamless user experience.

## 🛠️ Technologies Used

* **Language:** Java
* **GUI Framework:** Java Swing, AWT
* **Core Concepts:** OOP (Encapsulation, Inheritance, Polymorphism), Object Serialization, Data Structures (Collections), Event Handling.
